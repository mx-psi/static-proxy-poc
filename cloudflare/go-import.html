go-vanity-proxy.pages.dev/embedmod

This is a PoC on a static Go module proxy. See github.com/mx-psi/static-proxy-poc.

Fetch the module through the proxy and print its embedded, CI-generated notice:

mkdir demo && cd demo && go mod init demo
go get go-vanity-proxy.pages.dev/embedmod@latest

cat > main.go <<'EOF'
package main

import (
	"fmt"
	"go-vanity-proxy.pages.dev/embedmod"
)

func main() { fmt.Print(embedmod.Notice) }
EOF

go run .
